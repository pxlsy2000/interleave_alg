# 实现计划目录

本目录用于存放从 [产品规格](../spec.md)派生的实现计划。

## 计划的职责

实现计划负责说明：

- 为满足规格，需要交付哪些可观察结果；
- 工作如何拆分、排序和验证；
- 每一步对应产品规格中的哪些章节和验收标准；
- 实施过程中发现了哪些风险、依赖和待决事项。

实现计划不负责重新定义产品行为。若实现过程中发现规格需要改变，应先修改 `docs/spec.md`，再同步计划。

## 文件约定

- 每个独立实施主题使用一份 Markdown 文件；
- 文件名使用 `YYYY-MM-DD-<topic>.md`；
- 计划开头必须链接相关规格章节；
- 已完成的计划保留在本目录中，作为实现决策和验收依据。

当前尚无实施计划。
